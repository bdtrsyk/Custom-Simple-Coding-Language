          MYCODINGLANGUAGE Guide
          
Reference guide for writing real .mcl programs.


          

            

              
First Idea: Code Is A List Of Instructions

              
Write one instruction on each line. Press Run Program. The computer reads from top to bottom.

              
print "Hi"
print "I am learning code"
print "This runs third"

              
If you are stuck, start with print. It is the easiest command.

Rule 1: Text Gets Quotes

              
Words and symbols like + need quotes. Numbers do not.

              

                
ThingWrite it like this

                
Words"hello"

                
Math symbols as choices"+" "-" "*" "/"

                
Numbers10 3.5

              

              
print "hello"
print 10 + 5
print "10 + 5"

              
The first math line prints 15. The second one prints the words 10 + 5.

            


            

              
Say Something

              
print shows words or answers in the console.

              
print "Welcome"
print "My score is", 100
print "2 + 3 =", 2 + 3

              
Commas add spaces between things.

            


            

              
Remember Something

              
A variable is a box with a name. Put something in the box, then use it later.

              
let name = "Sabit"
let score = 10

print name
print score

              
Change a box with set.

              
let score = 10
set score = score + 5
set score += 1
print score

            


            

              
Put A Variable Inside Text

              
Use curly braces inside quotes.

              
let name = "Sabit"
let coins = 25

print "Hello, {name}!"
print "You have {coins} coins."

            


            

              
Ask The User

              
ask makes a question appear in the console. The answer is saved in a variable.

              
ask name "What is your name?"
print "Hello, {name}!"

              
ask is universal. It tries to guess the answer type.

              

                
User typesProgram sees

                
12a number

                
yestrue

                
hellotext

Use a stronger ask when you know what kind of answer you want.

Choose What Happens

              
if means “only do this if the answer is yes.”

              
ask number age "How old are you?"

if age >= 13
  print "Teen or older"
else
  print "Kid"
end

              
Important: every if needs an end.

            


            

              
More Than Two Choices

              
Use else if for another choice.

              
ask choice color ["red", "blue", "green"] "Pick a color:"

if color == "red"
  print "Warm color"
else if color == "blue"
  print "Cool color"
else
  print "Nice color"
end

              
Use == when you ask “is it the same?”

            


            

              
Repeat Things

              
repeat means “do this again.”

              
repeat 3
  print "Hello"
end

              
The special variable loop tells you which repeat you are on.

              
repeat 3
  print "Round", loop
end

            


            

              
Count From One Number To Another

              
1..5 means 1, 2, 3, 4, 5.

              
repeat number in 1..5
  print number
end

            


            

              
Calculator: Easiest Version

              
This calculator asks for two numbers and prints all answers.

              
print "Welcome to the calculator"

ask number first "First number:"
ask number second "Second number:"

print "Add:", first + second
print "Subtract:", first - second
print "Multiply:", first * second
print "Divide:", first / second

            


            

              
Calculator: Pick + - * Or /

              
Symbols are text choices, so they need quotes.

              
print "Welcome to the calculator"

ask number first "First number:"
ask choice op ["+", "-", "*", "/"] "Choose +, -, * or /:"
ask number second "Second number:"

if op == "+"
  print first + second
else if op == "-"
  print first - second
else if op == "*"
  print first * second
else
  print first / second
end

            


            

              
Lists: A Box With Many Things

              
A list holds many values.

              
let colors = ["red", "blue", "green"]

print colors
print colors[0]
print list.first(colors)
print list.last(colors)

              
Loop through a list like this:

              
for color in colors
  print color
end

            


            

              
Functions: Make Your Own Command

              
A function is a command you create.

              
func double(number)
  return number * 2
end

print double(5)

              
This prints 10.
