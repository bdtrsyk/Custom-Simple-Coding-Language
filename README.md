# My Coding Language IDE

My Coding Language IDE is a custom browser-based programming environment designed to make coding simple, visual, and beginner-friendly.

The project includes a modern dark-themed interface, multi-file support, a built-in console, syntax highlighting, starter projects, and a full learning guide directly inside the IDE.

- Browser-based IDE
- Custom `.mcl` programming language
- Interactive console system
- Syntax highlighting
- Multi-file workspace
- Starter projects
- Folder save/load support
- Built-in beginner coding guide
- Responsive UI design

## Built With

- HTML
- CSS
- JavaScript

## Goal

The goal of this project is to create a coding experience that feels simple and approachable for new programmers, especially kids and beginners.
