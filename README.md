# Custom Simple Coding Language (MCL)

## My Coding Language IDE

My Coding Language IDE is a custom, browser-based programming environment designed to make coding simple, visual, and beginner-friendly.

It features a modern dark-themed interface, multi-file support, an integrated console, syntax highlighting, starter projects, and a built-in learning guide directly inside the IDE.

The language is designed for beginners and focuses on easy-to-read commands and a simple structure that helps new programmers understand core programming concepts without complexity.

---

## Installation & Usage

1. Download or clone the repository  
2. Open `index.html` in any modern web browser  
3. Start coding using `.mcl` files inside the IDE  

---

## Features

- Browser-based IDE (no installation required)
- Custom `.mcl` programming language
- Interactive console system
- Syntax highlighting for better readability
- Multi-file workspace support
- Built-in starter projects
- Folder save and load system
- Beginner-friendly coding guide
- Responsive and modern UI design

---

## Built With

- HTML
- CSS
- JavaScript

---

## Project Goal

The goal of this project is to create a simple and approachable coding environment for beginners, especially students and first-time programmers. It focuses on clarity, accessibility, and learning fundamentals through an easy-to-use interface.
